## 1. 專案核心架構與設計理念 Prompt

> **目標**：建置一具有現代影展質感、支援響應式（RWD）側邊欄與導覽列、具備 5 大分頁切換的完整網頁。

```text
請依照開學至今所有之前所學，建議一個具有導覽列、側邊欄，並具有分頁的完整網頁。
影展主題是戒菸。
需要具有完整的SEO內容、Grid System、RWD 功能（可用手持裝置觀看可以顯示完整資訊）等。
需要將CSS檔案進行切割後放置在 CSS 檔案匣內。
需要將圖片放置在 images 檔案匣內。
